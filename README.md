# 数据分层建模工作台

离线版数仓分层建模工具，覆盖贴源层、明细层、汇总层、应用层的表结构设计、分区策略配置、质量规则编排与血缘关系管理，数据持久化到浏览器本地存储。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `data-layer-studio:entries` 这一项，或调用 `resetModule(模块)`。

## 键守恒工作台（明细层去重口径）

入口：侧边栏「键守恒工作台」（路由 `/dwd/key-conservation`），代码在
`frontend/src/data/key-conservation/` 与 `frontend/src/api/key-conservation-service.ts`，
独立持久化在浏览器 `data-layer-studio:key-conservation` 存储桶。

围绕「采样包 → 两套候选策略 → 键守恒矩阵 → 确认口径 → 封存」工作：

- 同一采样包的同一业务键分别套用**按事件时间留首条**（`FIRST_EVENT`）与
  **按版本号留末条**（`LAST_VERSION`），两套策略的分片结果与剔除指纹分桶存储、互不串写。
- 矩阵逐键对照两策略胜出行、两策略是否一致、**跨分区日期分流**与**空域命中**
  （业务键/事件时间/版本号空域），并列出每个被剔除行的指纹、顶替行与原因。
- 采样包、策略输出、口径、矩阵都带内容摘要（FNV-1a），同一摘要重放直接复用、不增加席位。
- 计算按稳定分片推进，可随时中断；续算只补齐尚未计算（或分片摘要已变化）的分片。
- 字段定义换版后旧矩阵立即失效，并逐项标出指纹发生漂移的业务键；失效矩阵不能导出口径。
- 候选口径导出给汇总层后处于「候选」态，**只有经确认的集合才允许进入 DWS**
  （汇总层建模页面仅列出已确认口径并做引用校验）。
- 回看区以明细层建模为主对象，核对明细表登记的「去重策略」与工作台确认集合是否一致。
- 封存一次生成共用封存号的三件套：`manifest` 清单、`pack_bundle` 打包件、`bookmark` 书签，
  均带独立摘要并可分别下载。
